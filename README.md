# 🎯 Number Guessing Game

A simple Python number guessing game where you choose a difficulty level and try to guess the randomly generated number.

## 🎮 How to Play

Choose a difficulty:

- **Easy** — 1 to 50
- **Medium** — 1 to 100
- **Hard** — 1 to 500

The game will tell you whether your guess is too high or too low.

Your attempts are counted, and you can choose to play again after winning.

## ✨ Features

- Three difficulty levels
- Random number generation
- Input validation
- Attempt counter
- Too high / too low hints
- Play again option
- Handles invalid inputs

## ▶️ How to Run

Make sure Python is installed, then run:

```bash
python number_guessing_game.py
